# Contributing to Lumide

Welcome to **Lumide**! While the project is currently **closed-source**, we highly value your feedback, bug reports, and feature suggestions. This repository serves as our public hub for tracking the evolution of the editor.

## 🐛 Found a Bug?
- **Check for existing issues**: Search to see if someone else has already reported it.
- **Provide context**: Use our **Bug Report** template.
- **Logs are key**: Lumide's **Log Viewer** (found in the Command Palette or Settings) allows you to copy detailed execution logs. Please include these in your report to help us fix issues faster.

## ✨ Have a Feature Idea?
- **Propose it**: Use our **Feature Request** template.
- **Join the Discord**: Discuss ideas with the community in our [Discord](https://discord.gg/VP6p5JQdgt).

## 🚀 Public Releases
This repository is the official home for Lumide's compiled releases. You can find the latest binaries for macOS and Windows on the [Releases](https://github.com/SoFluffyOS/lumide/releases) page.
