# Security Policy

## Reporting a Vulnerability

We take security seriously at **Lumide**. If you find a security vulnerability, please do not report it in a public issue.

Instead, please report it privately to the following email address:

- **Email**: hi@sofluffy.io

We will respond as quickly as possible and provide a timeline for a fix.

## Privacy Promise
- **Local-First**: Your code stays on your machine.
- **No Telemetry**: We don't track your keystrokes or project data.
- **Zero bloat**: No background analytics processes.
